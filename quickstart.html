OverviewQuickstart
Quickstart · about ten minutes

From clone to your
own Today page.

Five steps, recorded on a real laptop. Claude Code does most of the work; you answer a few questions. Each step links to its moment in the install film.

Manager, runner or Codex?
  1. 1

    Check what you need

    Most laptops already have the first three. Node is only for the optional console.

    Git

    any recent version

    Python 3.10+

    plus PyYAML, the only dependency

    Claude Code

    signed in (or Codex)

    Node 20+

    optional, for the console

    check your tools
    git --version
python3 --version   # 3.10 or newer
claude --version
node --version      # 20+, only for the console
  2. 2

    Get Sales Mama

    The whole system is a folder: your team's knowledge, accounts and tools, kept in git.

    clone
    git clone https://github.com/neam-lang/sales-mama.ai.git
cd sales-mama.ai
python3 -c "import yaml" 2>/dev/null || python3 -m pip install --user pyyaml
    Homebrew Python (PEP 668)? Add --break-system-packages to the pip line.
  3. 3

    Check it works

    The self-test runs every rule and tool on a copy of the demo data: sending, privacy, scoring, calendar, everything.

    self-test
    python3 scripts/selftest.py
213/213 passed
  4. 4

    Set yourself up with Claude Code

    Start Claude Code in the folder and ask in plain English. It checks your tools, then asks who you are, one question at a time.

    start Claude Code
    claude
    Set me up for Sales Mama

    It asks for

    Name and work emailMarkets: SG · MY · IN Territory and industriesQuota and targets Tone and signature
    Your profile is written to reps/<you>.md: readable, versioned, and only yours to change.
    A safety check confirms nothing can send without you.
    Your work email (git config user.email) is your identity: your accounts, your drafts, your calendar.
  5. 5

    Open the console optional

    The first run installs the console. Then open it in your browser: your own Today page, chat, calendar and book. It only renders; every change still goes through a skill.

    console
    npm run console     # then open http://localhost:4173
    Done. Your manager allocates accounts next. Each session starts with your queue: due follow-ups, hot accounts and quota left today.
Connect channels

Gmail and WhatsApp, one command each.

Tokens stay in ~/.config/sales-mama/, never in the repo. Run the WhatsApp one with ! inside Claude Code so you type the token yourself.

channels
python3 scripts/connect.py gmail --client-file <oauth-client.json>  # browser opens, click Allow
! python3 scripts/connect.py whatsapp                                # you type the token
python3 scripts/connect.py status
Sending: off · Gmail ok · WhatsApp ok
Gmail uses one Google OAuth client from your IT team (Workspace, Internal, scopes gmail.compose and gmail.readonly).
WhatsApp goes only through the WhatsApp Business Cloud API, to contacts with a recorded opt-in, with an approved template for first contact.
Sending is off until the manager sets enabled: true in knowledge/sending.yaml. Admin steps: SETUP.md · Connect channels.

Troubleshooting

If something stops you.

Ask Claude Code first: it tries the fix and explains it in one line. The full table is in SETUP.md, Part E.

pip install says “externally managed environment”
Homebrew Python follows PEP 668. Run python3 -m pip install --user --break-system-packages pyyaml. PyYAML is the only dependency.
Session start says it doesn't know who I am
Your identity is git config user.email, matched to reps/*.md. Ask Claude Code: “Set me up for Sales Mama”.
connect.py status: Gmail not connected
Run python3 scripts/connect.py gmail. The first time, add --client-file <path> with the OAuth client your manager gives you.
send.py: “sending is switched off”
Expected until the manager sets enabled: true in knowledge/sending.yaml, after DPO sign-off.
send.py blocks for the send window
Expected outside the market's window or on a holiday. Sales Mama tells you the next allowed window.
send.py: “changed since the preview”
The draft was edited after the preview. Run /mama-send again and re-approve.
A skill isn't found
Run python3 scripts/sync_skills.py, then start a new session.
Push rejected or a sync conflict
Run python3 scripts/sync.py. Sales Mama never force-pushes; if it persists it shows git status and stops.
The console doesn't start
It needs Node 20+ and a signed-in claude CLI. The first run installs its dependencies; then open http://localhost:4173.
