Why

Small teams lose deals to busywork, not to competitors.

Sales Mama takes the busywork. Each fix is a skill you can call by name, or just ask in plain English.

How it works

Overnight it finds. In the morning you decide.

The runner scans, scores and proposes at 02:00. The manager approves who gets which lead. Reps research, draft, review and approve. Sales Mama sends, logs and learns.

The repo is the system

Markdown, YAML and CSV in git. No servers, no database. Every change has a history.

Maths in scripts, judgement in the model

Scores and allocation are deterministic and explainable. The model writes; it never invents numbers.

People decide

Managers approve leads. Reps approve every send. Agents advise and prepare.

Get started

Four lines, then plain English.

Clone, check, and ask Claude Code to set you up. It asks one question at a time and writes your profile. About ten minutes.

Full quickstart
terminal
git clone https://github.com/neam-lang/sales-mama.ai.git && cd sales-mama.ai
python3 -m pip install --user pyyaml     # the only dependency
python3 scripts/selftest.py              # 213/213 passed
claude                                   # then type: Set me up for Sales Mama
